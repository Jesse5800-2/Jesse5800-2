# 2026-08-13

## Font setup gotcha (Firefly static blog)
- Fonts are wired via `src/config/fontConfig.ts` → `astro.config.mjs` `fonts` array → `FontSetup.astro` renders one `<Font>` per CSS var. Error `No data was found for the "<var>" family passed to the <Font> component` means Astro's font resolver silently dropped that family.
- Root cause was missing local package: every font listed in `fontConfig.ts` MUST be `pnpm add @fontsource/<font>` (or the per-weight package). If the npm package is absent AND the Fontsource metadata API (`api.fontsource.org`) is unreachable, resolution fails silently and the family is skipped.
- Fix applied: Zen Maru Gothic entry uses `provider: "npm"` (reads `node_modules/@fontsource/zen-maru-gothic` directly, offline-safe), with weights `["300","400","500","700","900"]`. `pnpm add @fontsource/zen-maru-gothic` was run by the user.
- Note: `pnpm` global binary is broken in this sandbox (resolves to wrong path); prefer `node_modules/.bin` or corepack. `npm` provider ignores requested subsets and uses the package's full `index.css`.
